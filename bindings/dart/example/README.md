# morflow_example

Runs Morflow pipelines in a Flutter app on Android, iOS, Linux, macOS and
Windows, with every plugin-free action pack bundled (listed under
`hooks.user_defines.morflow.packs` in `pubspec.yaml`). `integration_test/` runs
each pack on a device or the desktop:

```sh
flutter test integration_test
```

See the package README for testing against libraries built from this
checkout before they are released.
